# Ramp_Generator
Blender add-on for generating color ramps.

![RG-cover2](https://github.com/user-attachments/assets/fcadd3c3-6ffd-4e3a-bf0b-8143d758d39c)

Download this add-on here: https://extensions.blender.org/approval-queue/ramp-generator/

---

## Install

Needs Blender 4.2 or later. In Blender open Edit > Preferences > Get Extensions and search for Ramp Generator.

To build the zip yourself, run this in the repo folder:

```bash
blender --command extension build
```

The addon is `__init__.py`, plus `relay_updater.py` for its update checks. It depends on nothing but Blender.
