# Changelog

## 1.4.4

The source code is now in this repository, with the license it has always been released under.

- Added the GPL 3.0 license text and a copyright notice
- Set the extension id back to ramp_generator, the one used on the Blender store
- The package now lists exactly which files it holds
- Restored the store name and tags

## 1.4.3

Released on the Blender store on 2025-10-22.

- Added Tags

## 1.4.2

Released on the Blender store on 2025-08-22.

Improvement:
The Ramp Generator now works properly inside of Custom Groups.

## 1.4.0

Released on the Blender store on 2025-08-15.

Improvements:
- Re-worked the custom image sampler, it's now giving more accurate colors based of the image, limit color duplication and samples randomized area on each ramp generation.

## 1.3.6

Released on the Blender store on 2025-08-15.

Changes: Added Github repository to report issues.

## 1.3.5

Released on the Blender store on 2025-08-14.

Improvement:
- Better complimentary color interpolation.
- Added a custom image option to sample colors from an image.
- Changed the "Black & White" option to "Greyscale".
- New tagline.

## 1.2.0

Released on the Blender store on 2025-08-14.

Improvements
Node Detection:
ColorRamp node selection now properly detects active nodes (greyed out Generate option when no ramps are selected).
Color Palette Preset:
Added a new preset tab with premade color palettes.
Stripe Palette:
Added a new black and white striped option.
UI Enhancements:
Changed some naming and tab positioning.

## 1.0.0

Released on the Blender store on 2025-08-13.

Ramp Generator v1.0.0
Generate complementary color ramps in RGB space. Generate random vibrant ramps. Generate black & white ramps. Adjustable number of colors (2–30). Optional Organic Stops to randomize ramp point positions. Works directly on the selected Color Ramp node in the Shader Editor.
